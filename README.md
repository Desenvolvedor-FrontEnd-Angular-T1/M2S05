Cada exercício tem:
- `exercicio/src/app`: ponto de partida com comentários `TODO n` (cumulativo: já traz o resultado do dia anterior);
- `gabarito/src/app`: solução comentada (Angular 22);
- `gabarito17/src/app`: **somente professor**, o mesmo gabarito convertido para o Angular 17.3 (**não publicar para os alunos**);
- `LEIAME.md`: objetivo, passo a passo, critérios de pronto e erros comuns.

## Como usar um exercício
Crie o projeto (`ng new biblioteca-web`) e copie `exercicio/src/app` por cima de `src/app`. Use o `gabarito/` para conferir.

Os arquivos de `M2S04` (Guia, Plano, Kahoot etc. da semana anterior) permanecem na pasta como base.
